# Результаты выполнения

Автоматизация страниц Calendars, Modals и Ads сайта Practice Automation по заданию полуфинала «Волга-IT». Список Automation Tools считывается через Selenium на странице Form Fields и переносится в Message через запятую.

## Покрытие

- Calendars: 10 позитивных и 4 негативных проверки, включая отправку корректной даты и валидацию некорректной.
- Modals: 9 позитивных и 3 негативных проверки, включая успешную отправку формы, обязательность имени и ошибку адреса почты.
- Ads: 8 позитивных и 3 негативных проверки, включая задержку появления, закрытие и сохранение открытого окна при нажатии Escape.
- Form Fields: 8 дополнительных проверок, в том числе полный список из пяти Automation Tools и значение поля Message.

## Последний полный прогон

- **45 passed за 234.68 секунды** (26 сентября 2026 года).
- Все 45 результатов включены в `allure-report.zip`; итог Allure: 45 passed, 0 failed, 0 broken, 0 skipped.
- Для каждого теста создавалась отдельная сессия Chrome. При падении тестов предусмотрено сохранение скриншота и URL.
- Запуск проверен на Python 3.13 с Chrome for Testing 154.0.8037.57. Для локальной тестовой среды Chrome запускался с `CHROME_NO_SANDBOX=1`; обычный запуск этого параметра не требует.

Запуск на другой машине описан в `README.md`. Актуальные результаты GitHub Actions доступны в артефактах соответствующего запуска.
