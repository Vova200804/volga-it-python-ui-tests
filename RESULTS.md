# Результаты выполнения

Автоматизация тестирования страниц учебного сайта Practice Automation по заданию полуфинала «Волга-IT».

## Реализация

- Исследованы страницы Calendars, Modals и Ads; список Automation Tools считывается на странице Form Fields и переносится в Message.
- Код организован на Python 3.12+, Selenium и Pytest с Page Object Model. Для каждого теста создаётся отдельный Chrome.
- На требуемых страницах реализованы Calendars: 9 позитивных и 4 негативных случая; Modals: 8 и 3; Ads: 7 и 3.
- В Allure у каждого сценария есть название, описание ожидаемого результата и шаг. При падении сохраняются скриншот и URL.
- Задержка Ads измеряется от начала навигации через MutationObserver, запущенный до скриптов страницы.
- Невалидная календарная дата проверяется по inline-ошибке после потери фокуса. Тест ждёт и атрибут ошибки, и текст сообщения.
- На странице Form Fields проверена блокировка отправки при пустом обязательном имени.

## Проверка

- Полный запуск через `run-tests.ps1`: **42 passed** за 198.25 секунды. По страницам: Calendars 13, Ads 10, Form Fields 8, Modals 11.
- Выборочный запуск Form Fields из чистой копии без `.venv`: **8 passed**.
- Проверка независимости в обратном порядке страниц: **4 passed**.
- При намеренном падении теста Allure получил PNG-скриншот и URL. Контрольный тест не входит в основной набор.
- Итоговый Allure-отчёт: 42 успешных результата, каждый с описанием и шагом.
- Среда проверки: Python 3.13.0, Chrome for Testing 154.0.8037.57.

## Запуск

В PowerShell из каталога проекта:

```powershell
./run-tests.ps1
./make-allure-report.ps1
```

HTML-отчёт можно собрать в `allure-report/`; архив успешного прогона — `allure-report.zip`.
